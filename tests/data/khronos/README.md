# Khronos glTF sample assets (test data)

These files are unmodified copies of models from the Khronos Group
[glTF-Sample-Assets](https://github.com/KhronosGroup/glTF-Sample-Assets)
repository at commit `edc7c9e67c639d230715049ee31f9a96a6babbbe`. They are used only as test inputs.

Each model directory keeps its upstream `LICENSE.md` and `metadata.json`,
which are authoritative. All selected models are licensed under CC0-1.0 or
CC-BY-4.0. Models with trademark or non-permissive terms (for example
BoxTextured and Duck) were deliberately not included.
