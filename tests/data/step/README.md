# STEP fixtures written by Open CASCADE

These files were written by Open CASCADE Technology 8.0 (through the `cadquery-ocp-novtk`
8.0.1.1 Python bindings) -- an independent CAD kernel -- to test Aether3D's STEP reader
on another system's conventions (seam edges, full-circle edges, vertex loops, millimetre
units). They were generated once with the script below and are not regenerated by tests.

| file | shape | volume (OCCT, mm3, eps 1e-12) |
| --- | --- | --- |
| `occt_cylinder.step` | cylinder r 5, h 20 | 1570.796326794897 |
| `occt_plate_hole.step` | 80 x 40 x 10 box minus a through hole r 4 at (20, 20) | 31497.34517542563 |
| `occt_sphere.step` | sphere r 7 at (1, 2, 3) | 1436.7550402417328 |
| `occt_hemisphere.step` | sphere r 10 minus the box above z = 0 | 2094.395102393193 |
| `occt_cone.step` | cone r 6 to an apex, h 15 | 565.4866776461627 |

```python
from OCP.BRepPrimAPI import (
    BRepPrimAPI_MakeBox,
    BRepPrimAPI_MakeCone,
    BRepPrimAPI_MakeCylinder,
    BRepPrimAPI_MakeSphere,
)
from OCP.BRepAlgoAPI import BRepAlgoAPI_Cut
from OCP.gp import gp_Pnt, gp_Ax2, gp_Dir
from OCP.STEPControl import STEPControl_Writer, STEPControl_AsIs
from OCP.Interface import Interface_Static

Interface_Static.SetCVal_s("write.step.unit", "MM")


def write(shape, name):
    w = STEPControl_Writer()
    w.Transfer(shape, STEPControl_AsIs)
    w.Write(f"{name}.step")


write(BRepPrimAPI_MakeCylinder(5.0, 20.0).Shape(), "occt_cylinder")
box = BRepPrimAPI_MakeBox(80.0, 40.0, 10.0).Shape()
hole = BRepPrimAPI_MakeCylinder(gp_Ax2(gp_Pnt(20, 20, -5), gp_Dir(0, 0, 1)), 4.0, 20.0).Shape()
write(BRepAlgoAPI_Cut(box, hole).Shape(), "occt_plate_hole")
write(BRepPrimAPI_MakeSphere(gp_Pnt(1, 2, 3), 7.0).Shape(), "occt_sphere")
sphere = BRepPrimAPI_MakeSphere(gp_Pnt(0, 0, 0), 10.0).Shape()
upper = BRepPrimAPI_MakeBox(gp_Pnt(-20, -20, 0), 40.0, 40.0, 20.0).Shape()
write(BRepAlgoAPI_Cut(sphere, upper).Shape(), "occt_hemisphere")
write(BRepPrimAPI_MakeCone(6.0, 0.0, 15.0).Shape(), "occt_cone")
```
